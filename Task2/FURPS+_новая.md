| Код    | Требования                                                                                                                       | Комментарий  |
|--------|----------------------------------------------------------------------------------------------------------------------------------|--------------|
| **F**  | **Функциональные (Functionality)**                                                                                                   |              |
|     | Новый клиент видит на сайте список доступных депозитов с актуальными ставками                                                    |              |
|       | Клиент может подать на сайте заявку на депозит, оставив свой номер телефона и ФИО                                                |              |
|       | Менеджер кол-центра может изучить заявку в системе кол-центра                                                                    |              |
|       | Менеджер кол-центра может предложить клиенту особые условия на основе заявки                                                     |              |
|       | Клиент видит в интернет-банке список доступных депозитов с актуальными ставками и персонализированные ставки лично для него      |              |
|       | Клиент может через интернет-банк подать заявку на открытие депозита, указав счет и сумму                                         |              |
|       | Клиент можент подтвержить заявку на открытие депозита через интерент-банк с помощью СМС-кода                                     |              |
|       | Сотрудники бэк-офисов депозита и кредита могут видеть информацию по ставкам депозитов в АБС                                      |              |
|       | Сотрудники бэк-офиса кредита могут редактировать информацию по ставкам депозитов в АБС                                           |              |
|      | Сотрудник фронт-офиса может провести идентификацию клиента, видит его заявку в АБС                                               |              |
|      | Сотрудник бэк-офиса видит заявку клиента в АБС, может подтвердить условия депозита                                               |              |
|      | Клиент получает подтверждение условий и открытия депозита по СМС                                                                 |              |
| **U**  | **Удобство использования (Usability)**                                                                                               |              |
|       | Интерфейс работы будет максимально удобным для клиента.                                                                          |              |
|       | Нужно придерживаться системы дизайна для приложений, которая принята в компании                                                  |              |
|       | Пользователи при работе должны видеть привычные цвета и брендированные элементы                                                  |              |
| **R**  | **Надежность (Reliability)**                                                                                                         |              |
|       | Данные, передаваемые с сайта необходимо защищать с помощью механизма шифрования трафика                                          |              |
|       | Данные, передаваемые из интернет-банка необходимо защищать с помощью механизма шифрования                                        |              |
|       | Сервисы должны работать 24/7 и быть доступны в 99,9% случаев                                                                     |              |
|       | В случае сбоев в ЦОД необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку                     |              |
|       | Необходимо предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД |              |
| **P**  | **Производительность (Performance)**                                                                                                 |              |
|       | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды                                                 |              |
| **S**  | **Поддерживаемость (Supportability)**                                                                                                |              |
|       | Функционал работы с СМС реализован в ядре системы                                                                                |              |
|       | Необходимо вести документацию для дальнейшего расширения системы                                                                 |              |
| **+R** | **+ Ограничения (Restrictions)**                                                                                                     |              |
|       | Нужно как можно больше использовать технологии, которые уже есть в банке                                                         |              |
|       | Если используются новые технологии, они должны быть совместимы с существующими платформами разработки                            |              |
|       | Стек новых технологий зависит от текущей экспертизы сотрудников IT-отдела (как минимум на уровне ЯП)                             |              |
|       | Для очередей сообщений лучше использовать Kafka на перспективу                                                                   |              |
|       | В интернет-банке выделить сервис депозитов в отдельный микросервис                                                               |              |
|       | Необходимо избежать прямой работы интернет-банка с API АБС                                                                       |              |
|       | Необходимо учесть что АБС может масштабироваться только вертикально из-за своей базы данных                                      |              |
